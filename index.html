One brief · Three models

One brief. Three models. Two hundred balls.

Each model was handed the same prompt and no follow-up questions. Each returned a single self-contained file: two hundred numbered balls falling, colliding and settling inside a rotating heptagon, running on live rigid-body physics. All three are below, unedited.

The shared spec

Reconstructed from the three submissions. The original prompt was not kept, so this is what the code agrees on, not a quotation.

  • 200 labelled balls
  • one rotating regular heptagon
  • 1080 × 1920, portrait, scaled to fit
  • a single HTML file, p5.js from a CDN
  • live simulation, no pre-rendered animation
  • six timed acts, ending in a settle
  • audio stays silent until clicked
  • R restarts
